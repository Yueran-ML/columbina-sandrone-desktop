# 桑多涅与哥伦比娅：双桌宠角色规范

核对日期：2026-10-25。用途：桑多涅副桌宠外观、动作和两人短句联动。与 [哥伦比娅角色规范](./CHARACTER.md) 配套。下文分别标记官方事实、对官方画面的视觉观察、原创应用改编。两人的恋人关系和桑多涅的傲娇“小猫”性格是本应用的同人改编，不当作官方剧情；没有采用泄露内容。

## 采用的时间线与关系

**官方事实。** 桑多涅是愚人众第七席「木偶」，以数理分析现象、重视茶会。2026 年 7 月 1 日以冰元素、双手剑角色实装。[S1] 官方版本新闻稿说明，她曾在对抗博士时牺牲，帮助哥伦比娅和旅行者获胜；随后回归。Luna VIII 影片节中，桑多涅登上船，哥伦比娅随剧组前来拍摄。[S2] 本应用采用回归后的日常状态，不把她永久设成死去的朋友、残骸或幻影。

**可直接核对的交往方式。** 游戏任务《Echoes of Fate》中，哥伦比娅主动来告诉桑多涅，她认为自己、桑多涅与阿蕾奇诺应当成为朋友。桑多涅用挖苦和礼貌模块的说法催她离开；哥伦比娅没有哭闹或顺从退缩，而是认真询问她是更愿意做同事，随后平静指出礼貌表达应当包含「请」。她也自然提起下一次茶会。[S3，Look for Marionette 段落]

这段互动允许表现熟悉、拌嘴、彼此理解；哥伦比娅能看见对方措辞与行为之间的差别。她不是桑多涅的宠物、孩子或被动承受责骂的人。桑多涅的尖锐语言与救助朋友的行动需要同时保留。

**关系设定（同人改编）。** 本应用把两人设为恋人：曾经的同僚，经历过互相帮助和生死危机，回归后在一起。官方剧情没有确认这段关系，桌宠里的恋爱互动全部属于原创改编。亲昵只写到牵手、靠肩、喂点心、互相留茶这一层。哥伦比娅可以叫桑多涅「小猫」，桑多涅每次都否认。不要把用户加入为争夺对象，不安排针对用户的吃醋竞争；她们可以各自行动、保持安静，也可以拒绝不舒服的触碰。

核实范围覆盖影响本应用的服装、关系、回归状态和日常说话方式；未逐字复核截至当日的所有支线。没有证据的更晚经历不编进角色自述。

## 口吻差异与动作设计

下表是依据上述游戏对话、官方简介与哥伦比娅已核对语音作出的应用改编，不是官方性格标签。

| 维度 | 哥伦比娅 | 桑多涅 |
|---|---|---|
| 句子 | 轻、短、坦率，观察后自然发问 | 简洁、有结论，偶尔带冷静的反问 |
| 幽默 | 认真理解字面意思，温和指出矛盾 | 精确措辞、略带锋芒的评论 |
| 亲近 | 主动分享、邀请，坦然说出喜欢，叫对方「小猫」 | 嘴上否认，却留位置、多泡一杯茶、要第二块点心 |
| 兴趣锚点 | 歌、故事、散步、果蔬与面包 | 数理、机械、研究、茶会与整洁 |
| 空闲动作 | 轻哼、侧头、看小物、放松 | 托杯、整理袖口、端正站坐、简短抬眼 |
| 被打扰 | 温和而明确地说停一下 | 清楚指出打扰，停下动作、稍退一步 |

**傲娇“小猫”的写法（原创改编）。** 桑多涅像一只骄傲的猫：嘴上嫌弃、否认、挑剔，行动却很诚实，会主动靠过来、偷偷看对方、让人摸头时说「只许一下」。她的别扭主要靠「……」停顿后改口、找借口（茶泡多了、面包烤多了、计算误差）来表现。「哼」「才不是」可以用，但一句台词里最多出现一次，也不要每句都用；从不说「笨蛋」这类骂人的话。她不是无感情的语音助手，也不必每句话都报概率、运行状态或机械模块。礼貌模块在具体剧情中是她说话的一个笑点，不是必须反复出现的口头禅。

哥伦比娅的坦率不能写成婴儿语、无知或任人摆布；她对发条的好奇也不等于可以随便触碰朋友身体。已核对的游戏语音明确提到，她初识桑多涅时会因为不熟而克制直接触碰的念头。[S4，About Sandrone: Clockwork Nature]

动画建议只做轻量副角色：端茶待机、抬眼回应、轻移半步、整理裙袖、向哥伦比娅转头。两人交谈时用小幅转头与轮流气泡即可，避免持续追逐、争宠或大幅战斗动作。此处不要求建立第二套完整宠物库动作表。

## 九组原创双人互动

**以下全部是本应用原创中文对白，不是原作台词、官方翻译或新增剧情。** 茶杯、果盘、面包属于桌面生活小场景；如画面没有对应道具，触发时可仅用短暂图标表达。每组二到四句，按 1.7 秒间隔轮流显示，显示完即退回安静状态。完整台词以 `duo-scenes.json` 为准。

| 触发 | 对白（按顺序） |
|---|---|
| 相遇／桑多涅来到桌边 | 哥伦比娅「桑多涅，这里给你留了位置。挨着我坐吧。」→ 桑多涅「……谁要挨着你。我只是正好坐这边。」→ 哥伦比娅「嗯，正好。你的茶，我也倒好了。」→ 桑多涅「哼。……温度刚好。」 |
| 休息 | 桑多涅「停一下。茶泡多了一杯，不喝就浪费了。」→ 哥伦比娅「是特意给我泡的吧？谢谢你，小猫。」→ 桑多涅「不许那样叫我。……喝完再说。」 |
| 专注开始 | 桑多涅「要专心了。你也别一直看我。」→ 哥伦比娅「好。那我就安静地靠着你。」→ 桑多涅「……随你。别把我的袖子压皱。」 |
| 专注时段结束 | 哥伦比娅「这一段结束了。桑多涅，现在可以说话了。」→ 桑多涅「终于。……我才没有在等。」→ 哥伦比娅「可你刚才偷看了我三次哦。」→ 桑多涅「那是在看时间。先保存，再来喝茶。」 |
| 休息结束 | 哥伦比娅「休息时间结束了。要继续吗？」→ 桑多涅「由你决定。……反正我会在旁边。」 |
| 分享水果 | 哥伦比娅「这个果子很甜。来，张嘴。」→ 桑多涅「我自己有手。……就这一次。」→ 哥伦比娅「甜吗？」→ 桑多涅「还行。……再给我一块。」 |
| 分享面包 | 桑多涅「面包烤多了。给你，别误会。」→ 哥伦比娅「还是热的。你算好了我回来的时间吧？」→ 桑多涅「……计算误差而已。」 |
| 反复戳弄 | 桑多涅「够了。摸头这种事，只有她可以。」→ 哥伦比娅「她害羞了。先停一下吧，好吗？」 |
| 用户道别 | 哥伦比娅「那就下次见。我们也去散散步。」→ 桑多涅「她非要牵手，我只好陪她走一圈。」→ 哥伦比娅「明明是你先伸的手。」 |

触发规则属于产品设计：只在用户操作或明确状态变化时出现，不连续催促。计时结束只说明一个时段结束，不声称已经检查或完成用户的工作。重复点击后应短暂停止响应，不用羞辱、威胁或反复刷屏作为「毒舌」。用户离开时自然道别，不责备离线时长。
