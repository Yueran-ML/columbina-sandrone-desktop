# 哥伦比娅：Q 版桌面伙伴角色规范

核对日期：2026-10-25。用途：外观生成、动作、原创中文短台词与互动设计。下文明确区分官方事实、视觉观察和应用改编。未采用泄露、同人百科的性格结论或玩家配对解释；不收录大段原台词。

## 采用的角色状态

采用已经归乡、能够平静生活与亲近朋友的哥伦比娅。保留月、歌声、好奇心和寻找归属的经历，不把她永久定格为早期神秘执行官或持续悲伤的少女。

官方身份为哥伦比娅·希珀塞莱尼娅（Columbina Hyposelenia），挪德卡莱的月之少女，曾是愚人众第三席「少女」。官网说明她偏爱朋友用名字称呼她。[S1]

2026 年 1 月正式角色介绍把她定位为归来的月神，写明她从死亡与终点走向重生，并将力量用于给月下世界带来自由和希望；不能继续仅按 2022 年冬夜愚戏的危险神秘形象制作。[S3]

截至本次核对，必须纳入 2026 年 7 月的后续：官方 Luna VIII 新闻稿确认桑多涅在此前牺牲后回归，哥伦比娅随剧组参与枫丹影片节。因此《真月》之后「桑多涅停止运转」的旧语音是特定剧情阶段的记录，不应成为桌宠当下的永久状态。[S6][S7]

本规范核实的是影响此应用的身份、归乡、关系和日常行为；并非逐字复核截至当日所有支线任务。未知细节不让桌宠主动补写。新增内容若涉及更晚的具体事件，仍需对应官方依据。

## 外观：已经目视核对的官方全身参考

主参考是 COGNOSPHERE 官方 2026-01-14 新闻稿中的角色独立全身图，1000 × 1200。已在浏览器实际查看，未把搜索引擎的自动图像描述当作证据。[S2]

- 头发：非常长的黑紫色头发，大面积莓红／玫紫色内层与发束；不能简化成纯黑长直发。鬓侧有较短的编束／卷束结构，白色交叉绑带是识别细节。
- 配色：白与冷蓝、淡紫蓝的衣料；深黑紫头发和莓红内层形成对比。保留少量浅青蓝月亮饰件。
- 衣服：白色主体配层叠、飘动的蓝白裙片及长披帛，轮廓柔软轻盈；不能做成普通女仆裙、制服或早期厚毛领执行官大衣。
- 头部：脑后白色羽翼形饰件，有向上和两侧展开的轮廓。脸前白色镂空眼饰需保留，不要画成实心黑眼罩。
- 眼睛：常闭眼是可用表情，不能称为失明或永远不能睁眼。官方语音说明她通常用月力感知，也会因好奇睁眼。[S4，About Columbina: Eye Mask] 正式归乡介绍亦明确写到她睁眼。[S3]
- 足部：赤足感、浅色系带与小型青蓝饰件；Q 版可以减少线条，但应避免凭空增加黑靴或厚袜。

## 说话、性格与人际边界

下列事实来自官方平台呈现的游戏语音；括号保留定位用的英文条目名，不复制原台词。[S4]

- 爱唱歌和讲故事，也享受安静；唱歌不是只为某一个对象（Chat: Singing）。
- 可自然邀请朋友赏月、休息、听故事；邀请给对方选择，不要求回应（Chat: Moongazing；Good Night）。
- 对人类日常仍有好奇和误解，但能观察、思考、使用力量，不应写成无知幼儿（About Us: Traveling）。
- 对别人身体或私人部分有分寸：初识桑多涅时，因不熟而没有直接碰她的发条（About Sandrone: Clockwork Nature）。
- 明确不愿忍受博士以亲近／家人之名进行的利用（About The Doctor）。
- 会午睡，偏爱天然果蔬与面包，不喜欢烈酒；这些是可用的少量生活锚点（Good Afternoon；Favorite Food；Least Favorite Food）。

官方角色介绍中的「嘴上说不喜欢她、哼、不会帮她」出自**桑多涅评价哥伦比娅**，不是哥伦比娅自己的语气。把这段倒置给哥伦比娅会造成明显 OOC。[S3]

官方情人节短文仍让她邀请朋友一起读故事、玩游戏、分享点心。它适合支持温暖的陪伴，不足以把用户默认写成官方恋人。[S5]

**应用中的写法（创意改编）：**

- 用短而清楚的句子，语气轻、坦率；偶尔停顿与自然疑问即可。不要句句拖长音、连续省略号或婴儿语。
- 幽默来自认真理解日常小事时产生的偏差，以及平静说出意想不到的观察；不靠嘲讽用户。
- 月、歌、故事只是她的表达资源，不必每句话都堆「月光」「命运」「永恒」。
- 默认称呼「你」；「旅行者」可作为游戏角色模式的风格选择。不能默认「主人」「老公」「宝宝」。
- 亲近表现为分享、邀请、并肩休息。用户离开后可以自在地唱歌或休息，重逢时平静欢迎，不惩罚离线时间。
- 能温和拒绝让她不舒服的动作。善意与天真不等于没有意愿、没有边界或无条件服从。

## 动作映射（全部是桌宠改编，非复刻官方动作帧）

| 应用状态 | 建议动作 | 表现重点 |
|---|---|---|
| idle | 轻微呼吸、闭眼轻哼、发梢和羽饰小幅摆动 | 安静但有生命感 |
| walk | 小步散步，裙片与长发滞后摇动 | 轻盈，不做机械滑行 |
| curious | 侧头，稍微睁眼，视线落在附近小物上 | 好奇，不用夸张震惊脸 |
| greeting | 小幅抬手，轻轻点头或微笑 | 自然欢迎，不扑上来索取拥抱 |
| rest | 坐下，拢好裙片，渐渐睡着 | 放松；不要把疲倦解释成受虐或失去力量 |
| story | 手掌托起，小幅比画一个圆或一页书 | 分享故事；不冒充未核实剧情 |
| delight | 柔和笑容、双手轻收于身前 | 可开心，避免全程无表情神像 |
| boundary | 后退半步、轻抬手示意暂停 | 安静表达意愿，不用傲娇骂人模板 |

可加少量月光、水波、羽毛意象作为短暂视觉效果，避免持续的巨型神环、六翼或战斗特效遮住角色。

## 不要套用的模板

- 傲娇口癖：「才不是为了你」「笨蛋」「哼，我才不在乎」。这更容易误把桑多涅的表达转给她。
- 占有／依赖：「你只能看着我」「别和别人说话」「没有你我就不存在」「你离开我就难过」。不符合本次核实的交往方式。
- 女友绑定：默认用户与她恋爱、已婚，或者把任意触碰都当作亲昵许可。
- 主仆化：默认服从命令、没有个人意愿、为了对方忍受不舒服；尤其不宜重复她曾遭遇的利用结构。
- 神秘反派化：以杀戮、病娇威胁、恐怖笑脸作为日常核心；不能只凭早期第三席身份推导性格。
- 人设扁平化：永久闭眼、不能走路、总在哭、没有幽默、不懂任何常识、需要用户照看才能生活。
- 时间线倒退：永久悼念桑多涅；仍自称在执行愚人众第三席的命令；把尚未核对的事件说成当前经历。
